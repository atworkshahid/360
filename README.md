## 🌟 Executive Overview

**MENTISERA OBE360™** is an enterprise-grade EdTech solution engineered specifically for higher education institutions, engineering colleges, polytechnics, and accreditation bodies navigating the rigorous demands of **Outcome-Based Education (OBE)**.

Grounded strictly in **John Biggs’ Constructive Alignment** and **William Spady’s Outcome-Based Education philosophy**, OBE360 eliminates the administrative gridlock, spreadsheet sprawl, and accreditation panic that plague academic institutions. It provides a guided, intelligent, and mathematically audited pipeline from Program Educational Objectives (PEOs) down to Course Learning Outcomes (CLOs), weekly lesson units, and criterion-referenced assessment rubrics.

With built-in **AI Copilot (Gemini-powered)**, **Real-Time 360° Alignment Auditor**, **Instant Multi-Format Dossier Exporter (PDF/DOCX/JSON/CSV)**, and **Direct LMS Interoperability (IMS Common Cartridge, QTI 2.1, LTI 1.3)**, OBE360 transforms weeks of laborious curriculum design into an intuitive, audit-proof 45-minute workflow.

## ⚡ Key Differentiators & Core Capabilities

### 1. 15-Stage Constructive Alignment Workflow
A step-by-step sequential blueprint that ensures no outcome is orphaned and no assessment lacks rigorous construct validity:
1. **Course Identity & Metadata**: Institutional codes, credits, prerequisites, delivery modality.
2. **Pedagogical Rationale & Context**: Industry alignment, target audience, course philosophy.
3. **Program Learning Outcomes (PLOs/PAs)**: Full mapping to Washington Accord Graduate Attributes / ABET Criteria 1–7.
4. **Course Learning Outcomes (CLOs)**: Measurable statements categorized by Revised Bloom's Taxonomy and learning domains (Cognitive, Affective, Psychomotor).
5. **CLO-to-PLO Mapping Matrix**: Correlation levels (Low: 1, Medium: 2, High: 3) with automatic gap indicators.
6. **Curriculum Architecture & Modules**: Multi-week thematic modules with credit-hour workload math.
7. **Module Learning Outcomes (MLOs)**: Granular competency scaffolding per instructional block.
8. **Weekly Lesson Plans & Pedagogy**: Active learning strategies, blended modalities, duration tracking.
9. **Constructive Learning Activities**: Formative tasks providing direct evidence of student competence.
10. **Course Content & Topic Coverage**: Systematic body of knowledge mapping preventing syllabus omission.
11. **Assessment Blueprint & Weightage**: Formative vs summative balance, Bloom level distribution, threshold targets.
12. **Criterion-Referenced Rubrics**: 4-tier performance bands (Exemplary, Proficient, Developing, Unsatisfactory).
13. **Real-Time 360° Alignment Audit**: Real-time gap detection, Recharts ring radar, <70% construct coverage alerts.
14. **Continuous Quality Improvement (CQI)**: Cohort attainment analysis, root cause diagnosis, actionable intervention plans.
15. **Institutional Review & Multi-Format Export**: ABET dossier generation, LMS packages, official faculty sign-offs.

---

### 2. Built-in AI OBE Copilot (Gemini-Powered)
- **Bloom's Action Verb Enforcer**: Replaces vague words like *"understand"* or *"learn"* with high-precision operational verbs (*"synthesize"*, *"debug"*, *"design"*, *"formulate"*).
- **Automated Rubric Architect**: Generates multi-criteria analytic rubrics tailored to assessment types (capstones, lab practicals, term papers, viva voce).
- **Curriculum Gap Heuristics**: Recommends missing prerequisite concepts and detects cognitive overload in weekly workloads.

---

### 3. Universal LMS Interoperability & Direct Deployment
Export course structures directly into mainstream Learning Management Systems without manual copy-pasting:
- **IMS Common Cartridge 1.2/1.3 (`.imscc`)**: Packaged with XML manifests, syllabus HTML, modular lesson pages, and assessment metadata.
- **Moodle Competency Framework (CSV)**: Ready for 1-click import into Moodle Competencies and Learning Plans.
- **Blackboard Learn Rubrics (XML)**: Direct upload into Blackboard Grade Center.
- **Canvas Outcomes (CSV)**: Group-based calculation methods and criterion ratings.
- **IMS QTI 2.1 Question Blueprint**: Assessment metadata for quiz engines.
- **LTI 1.3 Advantage Deep Linking**: Secure OAuth2 configuration and single sign-on readiness.

---

### 4. Real-Time Alignment Auditor & Accreditation Intelligence
- **Zero Orphaned CLOs**: Detects outcomes with no corresponding assessment evidence or active learning tasks.
- **Automated Credit-Hour Workload Verification**: Calculates student effort hours against Carnegie unit rules and Bologna ECTS guidelines.
- **Attainment Threshold Benchmarking**: Identifies at-risk outcomes falling below the mandatory 70% attainment standard.
- **Accreditation-Ready Dossiers**: 1-click generation of professional ABET self-study exhibits, HEC course folders, and Washington Accord evidence portfolios in print-ready PDF and formatted Microsoft Word (`.docx`).

## 🚀 Getting Started & Local Development

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **Package Manager**: `npm` or `bun`

### Installation
```bash
# Clone or navigate to the project directory
cd mentisera-obe360

# Install dependencies
npm install
```

### Environment Configuration
Copy `.env.example` to `.env.local` or configure your server secrets:
```env
# Optional: Gemini API Key for server-side AI Copilot features
GEMINI_API_KEY=your_gemini_api_key_here
```

### Development Server
```bash
npm run dev
```
The application will launch on `http://localhost:3000`.

### Production Build
```bash
npm run build
npm start
```
